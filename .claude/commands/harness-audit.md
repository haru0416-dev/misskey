# /harness-audit

指定された指示・Skill・入口を読み取り専用で調べる。範囲が省略された場合は [AGENTS.md](../../AGENTS.md) の正本配置と各入口の接続を対象とし、無関係な個人設定・他セッションへ広げない。

- 同じ契約が独立編集されていないか、参照先が実在するか、対象操作に必要な本文へ到達できるかを確認する。
- `bun run lint:agent-instructions` で生成入口と正本の整合を検査する。監査中は生成・修正を行わず、不一致と修正すべき正本を報告する。
- 規則が参照するコマンド・設定・実装・既存テストを対象箇所だけ照合する。件数の一致だけで登録や安全性を判定せず、文書監査のために DB 接続・migration・全体テストを実行しない。
- 配置済みの規則と、実際のセッションへ渡された本文を分ける。読込記録が無ければ適用状況は未確認とする。
- 改善の主張に比較条件と実行結果があるかを確認する。短文化、ファイル数、hook の有無から性能・費用・品質を採点しない。hook や新しい入口は確認された必要性がある場合だけ候補にする。

出力は対象範囲、矛盾・重複・参照切れの箇所と根拠、保持すべき契約、修正先、未検証事項とその確認方法を返す。根拠のない総合点・順位・合格宣言は付けない。文書整合の成功を、既存挙動や安全性の比較評価に代用しない。
