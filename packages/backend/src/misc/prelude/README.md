# prelude

JavaScript の標準機能を補う、汎用の小さな関数を置く。Misskey 固有の処理には依存せず、コードを読みやすくするために使う。

| ファイル | 内容 |
| --- | --- |
| `array.ts` | 配列の連結と、要素の間への区切りの挿入 |
| `time.ts` | UTC の `Date` の作成、`Date` の比較、時間の加算と減算 |
| `url.ts` | クエリ文字列の組み立てと、URL への付加 |
| `xml.ts` | XML の値と属性のエスケープ |

Misskey 固有の概念(ノート、ユーザー、設定など)を知る処理は、`core/` か `misc/` に置く。
